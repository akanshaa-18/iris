# Iris

Iris is a project to Personalize Adobe.com pages on the edge. We do this to improve performance.

## Getting Started

We use node v22.16.0.
```bash
nvm install 22.16
nvm use 22.16
```

To bundle the code make sure that persmissions are set for the script `chmod +x ./bundle.sh` then do
```bash
npm run bundle
```
